# MVP System - Gerenciamento de Projetos (ADS)

## Sobre o Projeto
Este projeto tem como objetivo desenvolver um sistema web para gerenciamento de projetos acadêmicos do curso de Análise e Desenvolvimento de Sistemas (ADS).

O sistema permitirá:
- Cadastro de alunos
- Organização em grupos
- Vinculação de projetos
- Controle de entregas e apresentações
